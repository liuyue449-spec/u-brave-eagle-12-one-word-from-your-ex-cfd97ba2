One word from your ex: **exhausting**. The word an ex would use to describe you — painfully honest, instantly lands, and the kind of word people repeat because they have lived through it too. Entered on [make.fun](https://make.fun/?ref=y9xqfw0n&utm_source=github&utm_medium=readme&utm_campaign=u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) for the $2 "One Word From Your Ex" bounty.

## Run it

```sh
python3 main.py
```

Writes `exhausting` (10 bytes, no trailing newline) to `/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set — then reads it back to verify the file holds exactly the word.
